To use a modified, interface-compatible pystray version:
1. Exit the companion using its tray menu. If Start with League is enabled,
   turn it off while making changes so the watcher cannot relaunch the app.
2. Keep a backup, then edit or replace the Python source files in
   _internal/pystray with your interface-compatible version. Retain the
   package structure, license notices and Windows backend. If present,
   remove that package's __pycache__ directories after changing its source.
3. Start MayhemCompanion.exe again. The external pystray source is loaded at
   runtime; no application rebuild or signing key is needed for this change.
   You may enable Start with League again if desired.
